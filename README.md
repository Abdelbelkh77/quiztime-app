# Quiztime applicatie

## Beschrijving
Quiztime is een interactieve quizapplicatie gemaakt met JavaScript en Node.js. De speler beantwoordt twee quizvragen en verdient punten voor elk juist antwoord.

## Functionaliteiten
- De speler voert zijn naam in.
- De toegang is beveiligd met een wachtwoord.
- De quiz stelt twee vragen.
- De score wordt bijgehouden over meerdere speelrondes.
- De speler kan kiezen om opnieuw te spelen.
- Voor elk behaald punt verschijnt de boodschap "hoera".

## Gebruikte technologie
- JavaScript
- Node.js
- De ingebouwde readline-module voor gebruikersinvoer

## Uitvoeren
Installeer Node.js als dat nog niet gebeurd is. Open daarna een terminal in de projectmap en voer uit:

`node quiztime.mjs`
